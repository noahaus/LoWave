About LoWave

LoWave turns ordinary test instructions into automated browser tests. Describe what a person would do in the web app, in numbered English steps. LoWave reads those steps, looks at the live site, and builds a test you can run again.

A project holds one website and the step files that belong to it. Open a project, choose a steps file, then use Parse to generate the test and Test to run it. Each generated step shows whether it passed or failed.

Settings choose how LoWave talks to the model that interprets your steps. Those choices apply to every project.
