# Usability: create a calendar event and find it with search
# App: demo_app/calendar.html (http://localhost:3000/calendar.html)
# Covers: + New event dialog, Title/Date/Starts/Ends, category chips, Add event, search

1. Go to http://localhost:3000/calendar.html
2. The period label should say July 2026
3. Click + New event
4. The dialog heading should say New event
5. Type Vendor kickoff call into Title
6. Set Date to 2026-07-16
7. Set Starts to 10:00
8. Set Ends to 10:30
9. Click Work
10. Type Confirm agenda and attendees into Notes
11. Click Add event
12. Vendor kickoff call should appear on July 16
13. Type Vendor kickoff into Search events…
14. Click Vendor kickoff call
15. The dialog heading should say Edit event
16. Click Cancel
